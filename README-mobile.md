# 手机版（Android · PWA）使用说明

这个目录现在已经是一个合格的 **PWA**：加上了 `manifest.json`、Service Worker 离线缓存、应用图标、底部 Tab 和手机布局。Android Chrome 可以「安装到桌面」，像 App 一样全屏使用，断网也能打开。

## 一、先搞清楚一件事：PWA 必须是 HTTPS

| 场景 | 能否安装 | 能否离线 |
| --- | --- | --- |
| `file://` 双击打开 | ✗ | — |
| `http://192.168.x.x:8080`（局域网） | ✗（非安全上下文） | ✗ |
| `http://127.0.0.1:8080`（电脑本机） | ✓ 仅限本机调试 | ✓ |
| **`https://...`（GitHub Pages 等）** | **✓** | **✓** |

所以：**要装到手机并离线用，必须把这个文件夹放到一个 HTTPS 静态托管上。** 下面给两条路。

## 二、路线 1：GitHub Pages（推荐，免费 HTTPS）

1. 新建一个仓库（例如 `cet4`），把 `F:\英语备考` 下的所有文件上传上去；
2. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存；
3. 等 1—2 分钟，访问 `https://<你的用户名>.github.io/cet4/`；
4. 手机 Chrome 打开这个网址 → 右上角菜单 → **安装应用 / 添加到主屏幕**；
5. 从桌面图标启动，断网也能学。

> 注意：免费 Pages 的仓库是公开的。这个站点包含按刘晓艳词表整理的单词数据，介意公开的话可以用 Cloudflare Pages + Cloudflare Access，或等后续的 APK（数据打进本地，不公开）。
>
> 更新：改完文件重新上传即可。Service Worker 会缓存新版本，**重新打开两次**生效。

其他等价选择：Cloudflare Pages（可直接拖文件夹）、Netlify Drop、Vercel。要求只有一个：HTTPS + 静态文件。

## 三、路线 2：局域网先看效果（不能离线安装）

1. 双击 `启动本地服务器.bat`（电脑需装 Python）；
2. 手机和电脑连同一个 Wi-Fi；
3. 手机浏览器访问 `http://<电脑的 IPv4>:8080/`（在电脑上 `ipconfig` 查）；
4. 可以浏览、做题、记进度，也可以「添加到主屏幕」当快捷方式，但：
   - 不是独立窗口；
   - 没有 Service Worker 离线缓存（非 HTTPS）；
   - 电脑关机就打不开。

适合先看看手机布局，不适合日常用。

## 四、数据怎么迁到手机

1. 电脑上打开 `index.html` → 首页「设置与备份」→ **导出备份 JSON**；
2. 用微信文件传输助手 / 网盘 / 数据线把 JSON 传到手机；
3. 手机打开站点 → 首页「设置与备份」→ **导入备份**；
4. 词汇进度、错题本、笔记、真题记录、计划勾选都会恢复。

手机浏览器和电脑浏览器的数据是彼此独立的，导入导出是唯一的同步方式。

## 五、真题 PDF 怎么用（A + C 方案）

- **A**：把 `H:\doubao\四级备考\近五年四级真题` 整个文件夹拷到手机（`Documents/CET4/` 或 `Download/`），用手机文件管理器 / WPS / 系统 PDF 阅读器打开；
- **C**：站点里的「真题」页仍然负责 **125 分钟计时 → 录分 → 记错题**；
- 手机浏览器不允许网页直接打开 `file://` 链接，所以站点里的「试卷」按钮在手机上点了没反应是正常的，按页面顶部的提示用系统阅读器打开即可；
- 后续如果做 APK，可以把这个按钮接到系统阅读器，一步打开。

## 六、手机上已经适配了什么

- 底部 5 个 Tab：**今天 / 学习 / 复习 / 真题 / 更多**，单手可达；
- 顶部横向导航在手机上隐藏，桌面端不变；
- 弹窗变成底部抽屉；输入框 16px 防自动放大；
- 表格横向滚动；安全区适配（刘海、底部横条）；
- 图标：`icons/` 下 192 / 512 / maskable / apple-touch；
- 离线：Service Worker 预缓存 53 个文件（HTML/CSS/JS/数据/图标），断网可完整使用；
- 备份提醒：超过 7 天没导出，首页会出现提示条。

## 七、怎么更新内容

改完站点后执行：

```powershell
cd F:\英语备考
node tools/build-sw.mjs      # 重新生成预缓存清单（版本号会自动变）
node tools/check-pwa.mjs     # PWA 自检
node tests/validate-data.mjs # 数据自检
```

然后把改动上传到托管平台。手机上重新打开两次即可拿到新版。

## 八、常见问题

**菜单里没有「安装应用」？**
说明当前不是 HTTPS 或 Service Worker 没注册成功。确认地址是 `https://`，刷新一次再看。

**装完打开是白屏？**
先确认在电脑上访问同一 URL 正常；再用 Chrome 的「清除并重新加载」强制刷新一次。

**断网后数据还在吗？**
在。学习数据在浏览器的 localStorage 里，和离线缓存相互独立；但清理浏览器数据会一起清掉，所以每周导出一次备份。

**换手机怎么办？**
旧手机导出 JSON → 新手机打开同一网址 → 导入。知识内容在站点里，进度在备份里。

**iPhone 能用吗？**
能打开，也能「添加到主屏幕」，但 iOS 对 PWA 存储会做清理，且不支持定时通知；建议 Android 用 PWA，iPhone 只当网页用并勤备份。
