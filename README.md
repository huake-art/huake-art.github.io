# 四级备考站（本地离线版）

双击就能用的英语四级备考网站：**刘晓艳词书 + 近五年真题库 + 基础语法 + 记忆曲线 + 错题本 + 3 套模拟卷 + 60 天计划 + 课程笔记**。

- **不联网、不安装**：直接用 Edge / Chrome 打开 `index.html`。
- **数据在本地**：学习进度存这台电脑的浏览器（localStorage），换设备用首页「导出备份」。
- **素材在你自己的磁盘上**：真题 PDF 不复制进站点，只做索引、计时与记分；词表只提取「单词 / 词性 / 释义 / 章节」。

## 快速开始

1. 双击 `index.html`（推荐 Edge 或 Chrome）。
2. 首页 →「设置与备份」调**每日新词量**和**计划开始日**。
3. 词汇页右上角选词书（默认「刘晓艳 · 全程班」），学一组新词。
4. 真题页点「计时」→「试卷」打开 PDF，做完「录分」，错题用「⋯ → 记一道错题」。

## 手机 / PWA

本站已经可以装到 Android 桌面离线使用：

## 记忆曲线怎么算

单词间隔：`5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天`。

- **认识**：进一档，按新间隔排期（满 8 档记为「已掌握」）。
- **模糊**：档位不变，30 分钟后再见。
- **忘记**：归零，5 分钟后再来一次。

错题间隔：`1 → 2 → 4 → 7 → 15 → 30 天`；连续答对 3 次自动归档。三本词书共用同一份单词进度（同一个词在哪本书里都算已学）。

## 基础语法怎么用

- **顺序**：be 动词 → 三单 → 一般现在 → 一般过去 → 进行时 → 将来 → 现在完成 → 过去完成 → 被动 → 情态 → 主谓一致 → 非谓语；再补句型、名词、冠词、代词、形容词副词、介词。
- **每个单元**：规则 → 中英例句 → 易错清单 → 5—6 道练习。答错自动进错题本（模块「基础」），按错题曲线排期。
- **虚词库**：`of / for / to / with / in on at / by / from / about / as than like / 连词 / 结构短语 / 中式英语 20 条`，每条用法都有搭配和例句。
- **每日 5 题**：首页「今日任务」第 5 项，或基础页「每日 5 题」，从全部内容随机抽 5 题。

## 真题库怎么用

1. **计时**：点「计时」开始 125 分钟倒计时，顶部计时条会一直跟着你（刷新页面也不丢）。
2. **做题**：点「试卷」用浏览器打开 PDF；听力按考场规则一次听完。
3. **对答案**：整卷做完再看「答案」PDF，蒙对的也标出来。
4. **录分**：点「录分」填听力 / 阅读 / 写作 / 翻译，自动算 710 制总分；用时、错题数、复盘备注可一起记。
5. **错题**：点「⋯ → 记一道错题」，填题号、考点、正确答案和错因，自动进入错题本并按 1/2/4/7/15/30 天排期。

如果 PDF 打不开，通常是素材换了位置：真题页 →「真题目录」改成实际文件夹路径即可。路径只存在本机设置里。

## 素材更新后重新生成

素材加词或加卷后，在本目录运行：

```powershell
python tools/build-from-sources.py
```

默认读 `H:\doubao\四级备考\...`；换路径时用环境变量：

```powershell
$env:CET4_VOCAB_DIR='D:\我的资料\四级词汇'
$env:CET4_EXAM_DIR='D:\我的资料\四级真题'
python tools/build-from-sources.py
```

脚本只提取表格里的单词/词性/释义/章节名与 PDF 文件名，不读取、不复制正文。

## 已知限制

- 纯前端无后端：数据只在本机浏览器；换设备要导出/导入。
- 真题 PDF 依赖本地路径，移动文件夹后要在「真题目录」里改一次。
- 词书只含单词/词性/释义，没有音标和例句；需要例句时用「原创高频 398」词书。
- 听力练习用浏览器语音合成；真题听力请用你本地 PDF 配套的音频。
- 写作 / 翻译分数是自评，参考分档不是官方评分。
